# 🛍️ Shopee Product Performance Dashboard

An executive-style interactive Tableau dashboard designed to analyze 5,000 synthetic product records from Shopee. The dashboard provides actionable business insights into pricing strategies, category performance, store classifications, and customer rating distributions.

## 🎯 Key Metrics & Features

* **5 Executive KPI Cards:**
  * **Total Products:** 5,000 products
  * **Total Reviews:** 4.337,06K reviews
  * **Average Price:** Rp 539.086
  * **Average Rating:** 4.8 / 5.0
  * **Average Discount:** 14.6%
* **Store Type Distribution (Donut Chart):** Visualizes market share between *Official Mall* (25.24%) and *Star/Regular Sellers* (74.76%).
* **Category Performance (Bar Chart):** Ranks top-performing categories led by *Elektronik* and *Perawatan & Kecantikan*.
* **Rating Distribution per Category (Stacked Bar Chart):** Breaks down customer satisfaction into 100% normalized proportions.
* **Top 10 Product Detail Table:** Granular data table presenting product names, categories, store types, price, discount, rating, and popularity scores.
